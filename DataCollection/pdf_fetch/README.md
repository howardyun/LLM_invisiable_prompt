# arXiv计算机领域论文批量爬取工具
一款基于Python的爬虫工具，用于从 **arXiv** 学术仓库批量获取并下载计算机领域的PDF论文。支持自动检索链接、国内镜像加速、去重处理及健壮的错误处理，可高效收集学术资源。

## 项目概述
本工具可自动化完成 arXiv 计算机领域论文的采集流程，针对国内用户常见痛点（如官方下载速度慢、文件重复、批量请求不稳定），整合了**国内镜像加速**、**文件名规范化**、**请求频率控制**等功能。

适用于科研人员、学生或AI工程师，可批量获取计算机视觉、机器学习、人工智能等方向的论文，助力学术研究与技术学习。


## 核心功能
### 1. 多分类精准爬取
覆盖计算机领域7个核心细分方向，采用 arXiv 官方分类标签，具体对应如下：

| 分类标签       | 领域名称       | 领域说明                          |
|----------------|----------------|-----------------------------------|
| `cat:cs.AI`    | 人工智能       | 通用人工智能研究                  |
| `cat:cs.CV`    | 计算机视觉     | 图像/视频处理、视觉任务（如检测、分割） |
| `cat:cs.LG`    | 机器学习       | 机器学习算法、深度学习模型        |
| `cat:cs.CL`    | 计算语言学     | 自然语言处理（NLP）、语言模型     |
| `cat:cs.NE`    | 神经网络       | 神经网络架构设计与优化            |
| `cat:cs.SE`    | 软件工程       | 软件开发、测试与维护              |
| `cat:cs.CR`    | 密码学与安全   | 网络安全、加密算法                |


### 2. 下载优化
- **国内镜像加速**：自动将 arXiv 官方PDF链接（`https://arxiv.org/pdf/`）替换为国内镜像（`http://xxx.itp.ac.cn/pdf/`），突破国际带宽限制，大幅提升下载速度。
- **分块下载**：以1KB为单位分块写入大文件，避免网络中断导致的文件损坏。
- **频率控制**：内置延迟机制（下载间隔1秒，API请求间隔3秒），防止触发 arXiv 反爬策略。


### 3. 健壮性与易用性设计
- **文件名清理**：自动移除文件名中的非法字符（`< > : " / \ | ? *`），并将超长标题截断（最大100字符），避免系统保存错误。
- **去重处理**：通过`set()`数据结构自动过滤重复的PDF链接，确保本地无重复文件。
- **状态反馈**：实时统计下载成功/失败数量，并记录失败原因（如HTTP状态码、错误信息），便于问题排查。
- **分页支持**：将大量请求拆分为多批次，避免API超时。


## 环境准备
### 1. Python版本
需安装 **Python 3.6及以上**（已在Python 3.8+环境中测试通过）。

### 2. 依赖包安装
通过`requirements.txt`一键安装所有依赖：
```bash
pip install -r requirements.txt
```

各依赖包的用途与版本要求如下：

| 依赖包          | 版本要求       | 用途                                  |
|------------------|----------------|---------------------------------------|
| `requests`       | >=2.28.0       | 发送HTTP请求，调用arXiv API并下载PDF |
| `beautifulsoup4` | >=4.11.0       | 解析 arXiv API 返回的XML数据          |
| `tqdm`           | >=4.64.0       | 显示下载进度条                        |
| `lxml`           | >=4.9.0        | 作为BeautifulSoup的XML解析器          |


## 快速开始
### 1. 获取项目代码
将项目克隆或下载到本地：
```bash
git clone https://github.com/your-username/arXiv-Computer-Science-PDF-Crawler.git
cd arXiv-Computer-Science-PDF-Crawler
```
（注：将`your-username`替换为实际的GitHub用户名，若为本地项目可直接解压后进入目录）

### 2. 安装依赖
执行[环境准备](#环境准备)中提到的`pip install`命令，安装所有依赖包。

### 3. 运行爬虫
执行主脚本，默认配置为下载10000篇论文（每次请求获取1000篇）：
```bash
python pdf_fetch.py
```

### 4. 查找下载文件
论文将自动保存到项目根目录下的`arxiv_papers`文件夹（若不存在会自动创建），文件名对应论文标题（已清理非法字符）。


## 参数配置
可通过修改`pdf_fetch.py`中`if __name__ == "__main__":`代码块的参数，自定义爬虫行为：

| 参数名称          | 默认值    | 说明                                  | 修改方式                                  |
|-------------------|-----------|---------------------------------------|-------------------------------------------|
| `total_papers`    | 10000     | 需下载的论文总数                      | 修改`batch_download_by_category(total_papers=5000, ...)`（如改为5000篇） |
| `papers_per_request` | 1000  | 每次API请求获取的论文数量             | 修改`batch_download_by_category(..., papers_per_request=500)`（如改为500篇） |
| `save_dir`        | "arxiv_papers" | 论文保存目录                          | 修改`download_pdfs(..., save_dir="my_papers")`（如改为"my_papers"） |
| `delay`           | 1（秒）   | 两次下载之间的间隔时间                | 修改`download_pdfs(..., delay=2)`（如改为2秒，避免被封IP） |
| 爬取分类          | 7个CS领域 | 新增/删除需爬取的领域                 | 编辑`batch_download_by_category()`中的`categories`列表（如添加`cat:cs.RO`表示机器人学） |


## 代码模块详解
项目包含4个核心函数，各司其职完成爬取流程：

### 1. `fetch_pdf_links_from_arxiv(query="cat:cs.CV", max_results=100, start=0)`
#### 功能
根据指定的 arXiv 分类标签，调用API获取该分类下论文的有效PDF下载链接。

#### 参数说明
| 参数名称       | 类型    | 默认值       | 说明                                  |
|----------------|---------|--------------|---------------------------------------|
| `query`        | 字符串  | "cat:cs.CV"   | arXiv分类标签（如"cat:cs.AI"表示人工智能） |
| `max_results`  | 整数    | 100           | 每次API请求返回的最大论文数量          |
| `start`        | 整数    | 0             | 分页偏移量（用于批量获取多页结果）    |

#### 核心逻辑
1. 向 arXiv API 地址（`http://export.arxiv.org/api/query`）发送带参数的GET请求。
2. 使用`BeautifulSoup`解析XML响应，提取每个`<entry>`标签（每个标签对应一篇论文）。
3. 遍历论文标签，筛选出标题为"pdf"的链接（即PDF下载地址）。
4. 将官方链接替换为国内镜像，提升下载速度。
5. 返回格式：列表，每个元素为`(论文标题, PDF下载链接)`元组。


### 2. `sanitize_filename(filename)`
#### 功能
清理论文标题中的非法字符，生成符合系统规范的文件名。

#### 参数说明
| 参数名称   | 类型    | 说明          |
|------------|---------|---------------|
| `filename` | 字符串  | 原始论文标题  |

#### 核心逻辑
- 通过正则表达式`re.sub(r'[<>:"/\\|?*]', '_', filename)`，将非法字符替换为下划线。
- 返回清理后的安全文件名。


### 3. `download_pdfs(pdf_links, save_dir="arxiv_papers", delay=1)`
#### 功能
根据获取的PDF链接列表，批量下载论文并保存到本地目录。

#### 参数说明
| 参数名称       | 类型    | 默认值       | 说明                                  |
|----------------|---------|--------------|---------------------------------------|
| `pdf_links`    | 列表    | -            | `fetch_pdf_links_from_arxiv()`的返回结果（`(标题, 链接)`元组列表） |
| `save_dir`     | 字符串  | "arxiv_papers" | 本地保存目录                          |
| `delay`        | 整数    | 1             | 两次下载之间的间隔时间（秒），用于频率控制 |

#### 核心逻辑
1. 检查保存目录是否存在，若不存在则自动创建。
2. 使用`tqdm`生成下载进度条，直观展示进度。
3. 遍历每个`(标题, 链接)`元组：
   - 等待`delay`秒，避免请求过于频繁。
   - 携带浏览器模拟头（`User-Agent`）发送GET请求，避免被识别为爬虫。
   - 若响应状态码为200（请求成功），清理文件名并分块写入文件。
   - 若请求失败，记录失败原因（HTTP状态码或错误信息）到`failed_downloads`列表。
4. 下载结束后，打印汇总信息：`成功: X, 失败: Y`。


### 4. `batch_download_by_category(total_papers, papers_per_request)`
#### 功能
整合链接获取与下载流程，实现多分类论文的批量爬取。

#### 核心逻辑
1. 定义需爬取的计算机领域分类列表（`categories`）。
2. 遍历每个分类：
   - 计算所需API请求次数（`num_requests = (总论文数 // 分类数) // 每次请求数量 + 1`）。
   - 按分页批量获取该分类的论文链接，每次请求后等待3秒。
   - 若已获取的链接总数达到`total_papers`，提前终止循环。
3. 对所有链接去重（利用元组可哈希特性，通过`set()`去重后转为列表）。
4. 调用`download_pdfs()`，下载前`total_papers`篇唯一论文。


## 注意事项
1. **国内镜像有效性**  
   默认镜像地址（`http://xxx.itp.ac.cn/pdf/`）可能随时间失效。若出现下载失败，可替换为其他可用国内镜像，例如：
   - `http://mirror.arxiv.org/pdf/`
   - `http://arxiv.sjtu.edu.cn/pdf/`

2. **反爬风险规避**  
   请勿删除代码中的延迟逻辑（`time.sleep()`）。若频繁请求，arXiv可能封禁你的IP。若被封禁，建议等待1-2小时后重试，并增加`delay`参数值或减少`papers_per_request`。

3. **存储空间预留**  
   单篇PDF论文大小通常为1-10MB，若下载10000篇，需预留**10-100GB**存储空间。

4. **API使用规范**  
   arXiv公共API无严格请求上限，但建议单日请求不超过10000篇论文，避免给服务器造成负担。
